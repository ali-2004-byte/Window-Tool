# **NeuralLink Solutions**  
_A Multifunctional Desktop Application for Windows_

---

## **Overview**  
NeuralLink Solutions is an all-in-one software tool designed to simplify tasks, provide utility services, and enhance productivity. Built using Python and Tkinter, the application integrates several functionalities, including weather updates, clock, calendar, games, screenshots, file exploration, web browsing, and system information.  

---

## **Features**  

### **1. Weather Application**  
- Provides current weather details for any city.  
- Displays temperature, wind speed, humidity, pressure, and weather conditions.  

### **2. Clock**  
- Displays the current time in a digital format.  
- Updates dynamically every second.  

### **3. Calendar**  
- Interactive calendar with day, month, and year selection.  

### **4. Game (Ludo Dice Roller)**  
- A simple dice roller game for entertainment.  

### **5. Screenshot Tool**  
- Captures the current screen.  
- Saves the screenshot to a user-defined location in `.png` format.  

### **6. File Explorer**  
- Opens Windows Explorer to access files and folders.  

### **7. Web Access**  
- Quick access to Google and GitHub via integrated browser shortcuts.  

### **8. System Information Viewer**  
- Displays system details such as OS, version, machine type, processor, and RAM.  

### **9. Dark/Light Mode**  
- Switch between light and dark themes for better usability.  

---

## **Getting Started**  

### **Requirements**  
- Python 3.x  
- Tkinter (comes pre-installed with Python)  
- Additional Python Libraries:  
  - `psutil`  
  - `screen_brightness_control`  
  - `pycaw`  
  - `geopy`  
  - `timezonefinder`  
  - `requests`  
  - `pytz`  
  - `tkcalendar`  
  - `pyautogui`  

Install dependencies using:  
```bash
pip install psutil screen-brightness-control pycaw geopy timezonefinder requests pytz tkcalendar pyautogui
